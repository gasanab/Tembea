## 🔧 TECHNICAL DECISIONS

### Why TypeScript Accessor Functions?
Instead of complex type guards, we used simple accessor functions:
```typescript
const getStringProp = (key: string): string => (formData as any)[key] || "";
```
**Benefits**: Simple, maintainable, non-breaking

### Why Separate Booking Components?
Each listing type gets its own component instead of one giant component:
**Benefits**: Easier to maintain, customize, and optimize per type

### Why Sticky Widgets?
Research shows sticky CTAs increase conversions by 40%+:
**Benefits**: Always visible, reduces scroll friction, improves UX

### Why Live Previews for Partners?
Partners see exactly what guests will see:
**Benefits**: Reduces errors, builds confidence, faster completion
